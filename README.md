## Sobre o desafio

O objetivo foi reproduzir um layout em formato de bento grid a partir das referências para desktop e mobile, mantendo a organização visual dos cartões em diferentes tamanhos de tela.

## Funcionalidades

- Layout responsivo para desktop e dispositivos móveis.
- Reorganização dos cartões conforme a largura da tela.
- Estrutura semântica em HTML.
- Composição do layout com CSS Grid e Flexbox.
- Tipografia com Google Fonts.

## Aprendizados

O projeto ajudou a praticar:

- Planejamento de layouts com múltiplas linhas e colunas.
- Uso de `grid-column` e `grid-row` para posicionar cartões.
- Combinação de Grid no layout principal e Flexbox dentro dos componentes.
- Criação de media queries e reorganização do conteúdo no mobile.
- Ajustes de espaçamento, proporção e tipografia a partir de uma referência visual.

## Executar localmente

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` diretamente no navegador ou com o Live Server.
